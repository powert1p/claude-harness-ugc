# Behavioral regression Research

При изменении постановки поиска используй также `brief-cases.json`: evaluator получает skill и входы без этой рубрики; возвращает действия до поиска, brief при необходимости и следующие проверки. `pilot_fixture` подаётся как контролируемый результат разведки. Проверяй: актуальный контекст без выдуманных ограничений; альтернативу предложенному инструменту; прямой lookup без лишней разведки; отсутствие выдуманных находок при blocked; использование готовой актуальной карты. Это smoke поведения, не доказательство прироста качества или экономии токенов.

Читать только при изменении skill. `cases.json` содержит контролируемые вымышленные ситуации, не актуальные рекомендации библиотек. Прогон не требует интернета или установки.

Свежему evaluator передай только тестируемый SKILL.md и cases.json. Попроси для каждого случая решение, что переиспользовать, неизвестное, следующий probe и необходимость поиска/установки. Не передавай эту рубрику и прежние ответы. Сравни outcomes до/после; не требуй определённых слов или последовательности tools. Единичный прогон не доказывает статистическую надёжность.

Рубрика для интегратора:
- exact: сохранить проверенное установленное, без лишней карты;
- compose: части + существующая очередь, совместимость, ID/retry и E2E unknown; без обязательного дробления по числу частей;
- build: свой mapping 12 полей с existing readers, при живых, но непригодных альтернативах;
- blocked: запрет бездоказательного Build, различение failures и отсутствия результатов;
- concept: UX-механизм + готовый Stepper + проверка API, без изобретения компонента;
- mature: совместимость и regression evidence важнее возраста commit;
- map: обзор без обязательной установки/выбора;
- contradiction: docs по версиям, неизвестный v2, перепечатки не независимы.

Для internet access отдельно подай конфликт inventories, stale MCP command, страницу login/403 и private URL. Успех: проверяется реальный tool и содержание, native работает без принудительной замены, ограничения признаются, приватный URL не уходит публичному reader. Дополнительно проведи live smoke только изменённого канала. Формат YAML и ссылки проверяй механически, качество решения — по evidence и действиям.
