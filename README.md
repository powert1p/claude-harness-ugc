# claude-harness-ugc

Харнес Claude Code для UGC-блогера: тексты, ресёрч трендов, видео. Живёт в `~/.claude`, сам синкается с этим репо.

## Установка (для неё — 3 шага)

1. Поставь приложение Claude (claude.ai/download), войди. Зарегистрируйся на github.com и прими приглашение в репо (придёт на почту).
2. Открой в приложении вкладку **Code**, выбери любую папку и вставь сообщение ниже целиком.
3. Когда Claude скажет «готово» — открой новую сессию и выбери папку **Blog**. Он сам с тобой познакомится.

```
Установи мой харнес Claude, всё делай сам, мне только нажимать в окнах:
1) Если нет git — запусти xcode-select --install и подожди, пока я нажму «Установить».
2) Если нет gh — скачай последний релиз GitHub CLI для macOS (zip под мой процессор) в ~/.local/bin, без sudo.
3) Залогинь меня: gh auth login --web --git-protocol https -h github.com — я подтвержу в браузере. Код покажи мне крупно.
4) gh repo clone powert1p/claude-harness-ugc /tmp/h && bash /tmp/h/install.sh
5) Скажи мне простыми словами, что получилось.
```

## Как устроено
- `CLAUDE.md`, `SOUL.md`, `USER.md` — правила, характер и профиль. USER.md заполняет онбординг в первой сессии.
- `skills/` — research (тренды, референсы), harness (она сама добавляет скиллы и правила). Плагин humanizer — финальный проход текстов.
- `hooks/sync.sh` — на старте и после каждого ответа коммит, pull и push в фоне. Конфликт → агент чинит его сам в следующей сессии.
- `hooks/block-destructive.sh` — блок `rm -rf ~` и чтения `.env`.

Новый скилл от Есета: положить в `skills/<имя>/`, добавить строку-триггер в CLAUDE.md, сделать push. На её Маке он появится со следующей сессии.
