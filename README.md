# claude-harness-ugc

Харнес Claude Code для UGC-блогера: тексты, ресёрч трендов, видео.

## Установка

Поставь приложение Claude (claude.ai/download), открой вкладку **Code**, выбери любую папку и напиши:

```
Установи харнес: https://github.com/powert1p/claude-harness-ugc
```

Когда Claude скажет «готово» — открой новую сессию и выбери папку **Blog**. Он сам с тобой познакомится.

## Для Claude: как установить

Делай всё сам, человеку — только нажимать в системных окнах. Объясняй простыми словами, без терминов.

1. Нет `git` → `xcode-select --install`, попроси нажать «Установить» и дождись конца.
2. `rm -rf /tmp/h && git clone -q https://github.com/powert1p/claude-harness-ugc /tmp/h && bash /tmp/h/install.sh`
3. Скажи, что готово, и попроси открыть новую сессию в папке Blog.

Вход в GitHub не нужен — репо открытое.

## Как устроено
- `CLAUDE.md`, `SOUL.md` — правила и характер. `USER.template.md` → при установке копируется в `USER.md`, который заполняет онбординг; профиль живёт только на её Маке и в репо не уходит.
- `skills/` — research (тренды, референсы), harness (она сама добавляет скиллы и правила). Плагин humanizer — финальный проход текстов.
- `hooks/sync.sh` — на старте и после ответов подтягивает обновления из репо в фоне; её правки коммитятся локально. Конфликт → агент чинит его сам в следующей сессии.
- `hooks/block-destructive.sh` — блок `rm -rf ~` и чтения `.env`.

Новый скилл от Есета: положить в `skills/<имя>/`, добавить строку-триггер в CLAUDE.md, push. У неё — со следующей сессии.
